# 🕵️‍♂️ SNIPE — Сканер Внутренней Сети

**SNIPE (Scan Network, Identify Potential Endpoints)** — это веб-приложение на Django для сканирования локальной сети, определения IP-адресов, MAC-адресов, открытых портов, операционных систем и баннеров сервисов.

---

## 🔧 Функциональность

- ✅ Ввод IP-диапазона для сканирования (например, `192.168.1.0/24`)
- ✅ Определение MAC-адресов, OS, открытых TCP/UDP портов, баннеров
- ✅ Хранение истории сканирования в базе данных
- ✅ Экспорт результатов в JSON
- ✅ Фильтрация по IP и ОС
- ✅ Выбор протоколов TCP/UDP
- ✅ Очистка истории сканирования одной кнопкой
- ✅ Веб-интерфейс с Bootstrap

---

## 🔍 Зачем нужен этот проект?
- 🎓 Учебный пример сетевого сканера с веб-интерфейсом
- 🛡 Помощь в аудите локальной сети (офис, дом, учебная аудитория)
- 🧪 Инструмент для тестирования обнаружения устройств, открытых портов, аномалий
- 🧰 Основа для расширения: отчёты PDF, алерты, cron-сканирование и т.д.

---

## 🛠️ Стек технологий

- **Язык:** Python 3.12
- **Фреймворк:** Django 5.2
- **БД:** SQLite (можно заменить на PostgreSQL)
- **Сканер:** [`nmap`](https://nmap.org/) через Python
- **UI:** Bootstrap 5, HTML5
- **Парсинг сети:** `python-nmap`
